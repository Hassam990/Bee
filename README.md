# B's Carpet Cleaning Services

Website for B's Carpet Cleaning Services (Telford, Shrewsbury and Bridgnorth).
Sofa and upholstery cleaning, carpet cleaning, and local Rug Doctor hire.

Single-file site: `index.html` (HTML, CSS and JS, with GSAP loaded from cdnjs).

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
Repo Settings > Pages > Source: `main` branch, `/ (root)`.
